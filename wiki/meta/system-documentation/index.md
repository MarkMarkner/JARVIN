# JARVEN Systemdokumentation

Vollständige Dokumentation des **Claude-Obsidian** Systems, auf dem JARVEN basiert.

Diese Dokumentation dient ausschließlich dazu, die Architektur vollständig zu verstehen und unsere Erkenntnisse langfristig festzuhalten.

---

## 🎯 Zweck dieser Dokumentation

**JARVEN** ist eine persönliche Wissensbasis, die auf dem **Claude-Obsidian Schema v1** aufbaut. Diese Dokumentation erklärt:

- **Wie das System funktioniert**
- **Welche Regeln eingehalten werden müssen**
- **Wie das System langfristig wächst**
- **Welche Grenzen und Sicherheitsmaßnahmen es gibt**
- **Wie Mark OS später darauf zugreifen wird**

**Wichtig**: Die bestehende Architektur wird nicht verändert. Diese Dokumentation ist deskriptiv (erklärend), nicht präskriptiv (vorschreibend).
