## 🎯 Kern-Konzept

**Mark OS ist das Interface zu Claude-Obsidian (JARVIN)** — die kontrollierte Führungs- und Bedienebene über Marks getrennten privaten, beruflichen und unternehmerischen Datenräumen.

**Funktionsweise:**
```
JARVIN (Wissensbasis) → Claude-Obsidian (Intelligenz) → Mark OS (Interface) → Mark (Entscheidungen)
```

**3 Kernfunktionen:**
1. Hierarchische Sichten (Überblick → Details)
2. Zentrale Orchestrierung (Entities, Projekte, TODOs)
3. Entscheidungs-Unterstützung (Analyse → Empfehlung → Entscheidung)
