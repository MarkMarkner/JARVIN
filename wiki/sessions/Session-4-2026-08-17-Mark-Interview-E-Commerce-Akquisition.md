## 💬 INTERVIEW-ANTWORTEN

### Sektion 1: Strategie & Vision

**1. E-Commerce als Strategie-Säule**
```
E-Commerce ist ein Fundament, um Kapital zu generieren. 
Deswegen möchte ich ein funktionierendes Unternehmen mittels Verkäuferdarlehen kaufen. 

Wichtig ist:
- Max. 15 Stunden/Woche Zeit-Investition
- Strukturierter Workflow muss vorhanden sein
```

**2. Vision für E-Commerce Business**
```
Ein passives Business, welches wenig Arbeitsleistung von mir erfordert und skalierbar ist.
```

**3. Gelavije als Operatorin**
```
Gelavije kann als Operatorin fungieren. 

Das ist jedoch eine Option und sollte der Arbeitsumfang mehr werden.

BEDINGUNG: Ein entsprechendes Entgelt muss erwirtschaftet werden können, 
damit ein Gehalt für Gelavije ausgezahlt werden kann.
```

**4. Parallel-Strategie: Fix-und-Flip vs. E-Commerce**
```
E-Commerce als Einkommensfundament für das Fix & Flip Projekt ist eine Option, aber kein Muss.
```

**5. EK-Lücke Lösung verstehen**
```
Wenn wir einen stabilen positiven Cashflow mit E-Commerce erzeugen, 
hilft das gegenüber der Bank zu argumentieren und eine positive Entscheidung 
für die Finanzierung eines Immobilienprojekts zu erhalten.
```

---

### Sektion 2: Kandidaten-Kriterien

**6. Branche & Geschäftsmodell**
```
Onlinehandel und von einer Person steuerbar.
```

**7. Profitabilität & Finanzielle Ziele**
```
Mindestens 80-100.000€ Gewinn pro Jahr erzeugen. 

Ein Geschäftsführergehalt ist am Anfang nicht zwingend erforderlich, aber "nice to have".
```

**8. Größe & Kaufpreis**
```
Ich ziele auf ca. 200-250.000€ in Form eines 100% Verkäuferdarlehens an.
```

**9. Wachstums-Potenzial**
```
Skalierbar muss es sein, damit das Verkäuferdarlehen schnell getilgt werden kann (ca. 3-6 Jahre).
```

**10. Verkäufer-Struktur & Deal-Typen**
```
100% Verkäuferdarlehen — zwei Geschäftsleute, ein Deal, keine Bank!
```

**11. Due Diligence & Red Flags**
```
Das Unternehmen muss nachweislich Gewinne erwirtschaften und mindestens 3-5 Jahre am Markt sein. 

Ich kaufe keine Hoffnung oder Versprechen.
```

---

### Sektion 3: Finanzierung & Struktur

**12. Finanzierungs-Quellen**
```
100% Verkäuferdarlehen. Dann würde ich auch mehr zahlen als der Verkäufer verlangt.
```

**13. Gelavije's Kapital-Rolle**
```
Für Gelavije kann es eine Aufgabe sein. Sie investiert hier aber kein Geld.
```

**14. Verkäuferdarlehen-Optionen**
```
Keine Option! (= 100% Verkäuferdarlehen ist die Struktur)
```

**15. Cashflow-Timing für Fix-und-Flip**
```
Da das Unternehmen als Tochterunternehmen der Holding zugekauft wird, 
können Gewinne entsprechend umgeschichtet werden und späteren Immobilien-Investments zugute kommen. 

Aktuell ist es als Option zu betrachten und nicht als Bedingung.
```

**16. Integration in Holding & Governance**
```
Unternehmen muss als Tochter-Gesellschafter entschuldigen, gekauft werden.
```

Ich habe aktuell zehn mögliche Kandidaten.

**18. Timeline bis Deal**

Ich möchte bis Ende der Woche alle Kandidaten angerufen haben,

**20. Success-Kriterium für "Gekauft"**

### Sektion 5: Risiken & Generationen-Strategie

**21. Biggest Risks**
```
Ein Unternehmen zu kaufen, welches die beschriebenen Bedingungen nicht erfüllt 
und ein Minusgeschäft darstellt. 

KRITISCH: Es dürfen in keinem Fall Schulden erzeugt werden, 
die nicht vom Unternehmen durch positiven Cashflow abgefangen werden können.
```

**22. Gelavije's Langfrist-Rolle**
```
Noch unklar.
```

**23. Holding-Vision mit E-Commerce + Fix-und-Flip**
```
Das E-Commerce Unternehmen zahlt überschüssige Gewinne, 
die nicht für die Skalierung investiert wurden, an die Holding. 

Die Holding verteilt überschüssige Gewinne, um Immobilien-Investments zu realisieren. 

Beispiel: Gelder können an Fix & Flip GmbH oder an eine Privatperson 
in Form von Darlehen ausgezahlt werden, welche nach erfolgreicher Fertigstellung 
der Projektentwicklung durch ein Bankendarlehen getilgt werden.
```
